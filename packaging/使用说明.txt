超哥话探
SIP · RTP 通话分析

启动
适用于 Windows 10 / Windows 11 64 位。完整解压后双击 ChaogeHuatan.exe；请保留同目录的 app 和 runtime 文件夹，不需要另装 Java。

导入与切换
点击「导入抓包」，用 Ctrl / Shift 多选 PCAP / PCAPNG；也可以把多个文件拖入窗口。
通过顶部文件下拉框切换，每个抓包独立分析。再次导入可以追加文件；「关闭文件」只移除列表项，保留原始抓包。
每个文件保留自己的搜索、通话筛选和页面；切换时停止音频并重新读取所选文件。退出应用后需要重新导入。

TLS 密钥独立导入
PCAP 与 TLS key log 分别导入，可以先导入任意一种。点击「导入 TLS 密钥」选择 NSS key log 文件，追加后自动重新分析当前抓包并保留筛选条件。点击已加载的「TLS 密钥」可追加或清除；已加载的密钥适用于本次会话内的其他抓包。
密钥只保留在内存，退出后需重新导入。需要匹配的 TLS 会话密钥和 ClientHello / ServerHello，证书或服务器私钥不能代替 key log。
支持 SIP over WS、TLS 1.2 / 1.3、WSS；WS 可还原掩码、分片和 permessage-deflate 压缩的 SIP 消息。

查看信令和按键
先在左侧「找通话」输入号码、IP 或 Call-ID；点击「筛选」可组合主叫、被叫、信令或媒体 IP、开始和结束时间。各条件同时匹配，号码和 IP 可只填一部分。
时间按本机时区，可填 14:30:00 或 2026-11-05 14:30:00，也支持三位毫秒；匹配与该时间段重叠的通话，只填时分秒时可跨午夜。点「全部」清除通话筛选。
选择通话后查看完整 SIP 流序图，点击箭头查看报文。也可切换 SIP、RTP 和按键列表。
顶部搜索用于筛选报文或媒体，支持 IP、端口、Call-ID、SIP 方法、正文、编码和按键。
按键支持 RFC 2833 / 4733、SIP INFO 和 In-band DTMF，并显示类型。

播放与波形
双击 RTP 流播放，或勾选同一通话的流后「播放选中」。支持 G.711、G.729 和 Opus。Opus 保留 48 kHz 输出，立体声合并为单路方向音频。
双向波形按蓝色和橙色分上下两路。点「展开播放器 / 收起播放器」调整显示，收起后仍可播放或暂停。
使用「− / ＋ / 全览」或 Ctrl＋滚轮缩放；Shift＋滚轮或横向滚动条平移。点击波形或按键标签定位。
可以导出 WAV。红色表示抓包中缺包，黄色表示到达延迟风险，绿色表示按键。

使用范围
分析和音频还原在本机离线完成。可点击「体验演示」了解功能。
单文件上限 1 GiB（1024 MiB），RTP 载荷使用临时磁盘缓存；请为系统临时目录预留至少 2 GB 空间。切换文件或正常退出时清理缓存。
最多 2000 万包、3 万条 SIP 消息，TCP 重组上限 24 MiB；单次音频最长 60 分钟。
中断抓包会分析已经写入的可解析内容。TLS / WSS 信令可配合 key log 解密；SRTP 媒体暂不解密。TLS 信令成功解密后，还需确认媒体未加密且编码受支持。
缺包和延迟是抓包侧证据，实际通话听感还受网络和终端影响；In-band 按键是音频检测结果，可能遗漏或误识别。
暂不处理 TLS 1.0 / 1.1、0-RTT、DTLS-SRTP 或厂商自定义 WebSocket JSON 信令。
「本机抓包」需要另行安装 Wireshark / tshark 和 Npcap；导入已有文件不需要它们。

第三方组件及许可见「第三方许可.txt」和应用中的「关于」。
