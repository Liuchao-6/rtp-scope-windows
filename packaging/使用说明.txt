超哥话探
SIP · RTP 通话分析

启动
适用于 Windows 10 / Windows 11 64 位。完整解压后双击 ChaogeHuatan.exe；请保留同目录的 app 和 runtime 文件夹，不需要另装 Java。

检查更新
点击右上角「检查更新」，查看 GitHub 最新正式版及更新说明。「前往下载」会打开官方发布页；下载应用的 win-x64.zip，完整解压到新目录，关闭旧版后运行其中的 ChaogeHuatan.exe。用户目录中的已导入模型和解析索引可继续使用。
默认启动后每 24 小时最多后台查询一次，发现新版后提醒；支持「稍后提醒」「忽略此版本」。忽略只针对该版本，手动检查仍可查看它；后续更高版本仍会提醒。「更多 → 启动时检查更新」可关闭自动查询。
检查仅读取公开版本信息，无需 GitHub 登录，不上传抓包、录音或密钥。网络不可用时仍可离线分析，启动检查失败时不弹窗；手动检查可重试或直接打开发布页。支持 Windows 系统代理，网络仍需能访问 GitHub。
设置保存在用户目录 .chaoge-huatan/update.properties。旧版首次需手动升级到包含此功能的新版，之后才能收到应用内提醒。

导入与切换
点击「导入抓包」，用 Ctrl / Shift 多选 PCAP / PCAPNG；也可以把多个文件拖入窗口。
通过顶部文件下拉框切换，每个抓包独立分析。再次导入可以追加文件；「关闭文件」只移除列表项，保留原始抓包。
每个文件保留自己的搜索、通话筛选和页面；切换时停止音频并重新读取所选文件。退出应用后需要重新导入。

解密密钥独立导入
PCAP 与密钥可按任意顺序分别导入。点击「解密密钥」，选择「导入 RSA 私钥」或「导入 TLS key log」。追加或清除后自动重新分析当前抓包，保留筛选条件；切换文件后继续使用已加载的密钥。
RSA 私钥：适配 Wireshark RSA keys list 使用的 .key / .pem / .der，支持未加密 PKCS#1 / PKCS#8；可用于 TLS 1.0～1.2 的 RSA 密钥交换。AES-GCM、AES-CBC、3DES-CBC 已验证。证书、公钥或需要密码的加密私钥不适用于此入口。
TLS key log：包含 CLIENT_RANDOM / TRAFFIC_SECRET 的 NSS 会话密钥日志；ECDHE / DHE、TLS 1.3 或单独抓到的复用会话需要这种文件。
RSA 解密需要 ClientHello、ServerHello、ClientKeyExchange，扩展主密钥还需完整初始握手。抓包缺少握手或私钥不匹配时，可在「更多 → 分析提示」查看原因。
密钥只保留在内存，退出后需重新导入。WS / WSS 可还原掩码、分片和 permessage-deflate 压缩的 SIP 消息。

查看信令和按键
先在左侧「找通话」输入号码、IP 或 Call-ID；点击「筛选」可组合主叫、被叫、信令或媒体 IP、开始和结束时间。各条件同时匹配，号码和 IP 可只填一部分。
时间按本机时区，可填 14:30:00 或 2026-11-05 14:30:00，也支持三位毫秒；匹配与该时间段重叠的通话，只填时分秒时可跨午夜。点「全部」清除通话筛选。
选择通话后查看完整 SIP 流序图，点击箭头查看报文。也可切换 SIP、RTP 和按键列表。
顶部搜索用于筛选报文或媒体，支持 IP、端口、Call-ID、SIP 方法、正文、编码和按键。
按键支持 RFC 2833 / 4733、SIP INFO 和 In-band DTMF，并显示类型。

播放与波形
双击 RTP 流播放，或勾选同一通话的流后「播放选中」。支持 G.711、G.729 和 Opus。Opus 保留 48 kHz 输出，立体声合并为单路方向音频。
双向波形按蓝色和橙色分上下两路。点「展开播放器 / 收起播放器」调整显示，收起后仍可播放或暂停。
使用「− / ＋ / 全览」或 Ctrl＋滚轮缩放；Shift＋滚轮或横向滚动条平移。点击波形或按键标签定位。
「导出 WAV」生成一个文件，每路媒体方向对应一个独立声道：两路为双声道，三路为三声道，按波形从上到下排列并按抓包时间对齐。试听的静音、倍速和左右输出设置不改变导出内容。
导出支持 1～64 声道，最长 60 分钟，单文件不超过 RIFF 4 GiB 上限；超过双声道使用扩展 PCM WAV，支持多声道的音频工具可逐路查看，普通播放器可能合并播放。导出失败时保留目标位置已有的文件。
红色表示抓包中缺包，黄色表示到达延迟风险，紫色表示时间戳衔接，绿色表示按键。异常 RTP 时间戳会按抓包时间分段衔接，保留正常时序与静音；原始抓包内容不变。

使用范围
分析和音频还原在本机离线完成。可点击「更多 → 体验演示」了解功能。
单文件上限 1 GiB（1024 MiB），RTP 载荷使用临时磁盘缓存；请为系统临时目录预留至少 2 GB 空间。切换文件或正常退出时清理缓存。
最多 2000 万包、3 万条 SIP 消息，TCP 重组上限 24 MiB；单次音频最长 60 分钟。
中断抓包会分析已经写入的可解析内容。TLS / WSS 信令可配合 RSA 私钥或 key log 解密；SRTP 媒体暂不解密。TLS 信令成功解密后，还需确认媒体未加密且编码受支持。
缺包和延迟是抓包侧证据，实际通话听感还受网络和终端影响；In-band 按键是音频检测结果，可能遗漏或误识别。
暂不处理加密私钥、TLS 再协商、0-RTT、DTLS-SRTP 或厂商自定义 WebSocket JSON 信令。
「更多 → 启动 / 停止抓包」需要另行安装 Wireshark / tshark 和 Npcap；导入已有文件不需要它们。

第三方组件及许可见「第三方许可.txt」和应用中的「关于」。

新增通话工具
选择通话后打开「通话体检」查看时间、时长、结束方和证据，可导出 PCAPNG / WAV / HTML；单项或单方向失败后继续处理其余内容，并提供导出结果说明。也可从顶部「通话工具」进入导出、关联与对照，或选择另一处抓包校准对照。TCP / TLS 导出包含完整关联连接，可能有其他通话；报告遮蔽只作用于报告。跨 Call-ID 关联区分字段证据与候选，可手动确认和定位。

新增试听与编码
播放器「试听设置」提供方向独听、静音、左右声道、倍速和 A/B 循环。支持 G.722 64 kbit/s 和常见 AMR-NB / WB 单声道 RTP，不支持 AMR CRC、robust sorting、交织。

离线转文字
「录音转文字」可导入 WAV、MP3、M4A / AAC、FLAC。先下载配套 Huatan-SenseVoice-int8.zip，在「导入模型包」选择，无需解压。RTP 页的「转写当前通话」也进入此工作区。模型仅需导入一次，后续离线运行。
双声道默认分别识别，可选择混合；支持搜索、回听、声道改名，以及 TXT / SRT 合并或分别导出。时间戳为原录音中的语音片段范围，不保证逐字对齐；识别结果请回听确认。

索引缓存
无解密密钥时复用本地解析索引；文件、解析版本或密钥改变时重新分析。索引位于用户目录 .chaoge-huatan/index，可在应用退出后删除以释放空间。
