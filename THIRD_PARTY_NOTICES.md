## Build and test tools

Eclipse ECJ is a build-only compiler and is not shipped in the portable application or source ZIP. FFmpeg was used as an independent decoder oracle for the synthetic G.729 reference fixture; FFmpeg is not included. Wireshark / tshark and Npcap are optional, separately installed tools and are not bundled.


## Concentus Opus

Source: https://github.com/lostromb/concentus. Fixed revision and the SHA-256 of each unchanged Java source are in `third_party/concentus-upstream.json`. BSD-3-Clause license is included in the application assets/resources as `licenses/concentus-LICENSE.txt`. Stereo RTP audio is downmixed into a mono direction track; Opus playback retains 48 kHz output.

## Bouncy Castle lightweight cryptography

Component: bcprov-jdk15to18 1.78.1, MIT license. Source URL and SHA-256 are in `third_party/bouncycastle.json`. The unmodified binary provides authenticated TLS record cipher primitives; no global security provider is registered. The complete license is included as `licenses/bouncycastle-LICENSE.txt`.


## G.722

The 64 kbit/s decoder is a Java port of the Steve Underwood / CMU decoder. Attribution and public-domain dedication are retained in `licenses/g722-LICENSE.txt`. Independent PCM references are generated by FFmpeg.

## Offline speech

sherpa-onnx 2.0.1, Apache-2.0, https://github.com/k2-fsa/sherpa-onnx. JVM / platform runtime hashes are recorded in `third_party/sherpa-onnx.json`; licenses are embedded in the application. Android uses the JVM configuration API with matching native configuration fields and the unmodified Android JNI libraries. This is statically checked; device execution requires acceptance testing.

The optional multilingual Whisper tiny int8 model is distributed separately under the Whisper MIT license (https://github.com/openai/whisper). Model source and hashes are in `third_party/whisper-tiny.json`; the model ZIP includes the notices. No test recordings are included in the model ZIP.

Model license snapshot: https://github.com/modelscope/FunASR/blob/d8e676649df42801ceb1486c562428e82fd37540/MODEL_LICENSE . No test audio is distributed in the model package.

OpenCC 1.1.9 TSCharacters and TSPhrases dictionaries, Apache-2.0, https://github.com/BYVoid/OpenCC/tree/ver.1.1.9 .
